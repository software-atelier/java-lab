Notebook settings
Variables and Maven libraries belong to this notebook. Use labVar("NAME") or requireLabVar("NAME") in Java cells.
Variables & credentials
Names, environment mappings and non-secret defaults are saved in the notebook. Local values stay outside the document. Never print credentials in cell output.
Maven libraries
Use groupId:artifactId:version. Transitive dependencies are loaded when this notebook's kernel starts.
