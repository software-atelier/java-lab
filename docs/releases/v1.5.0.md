# Java Lab 1.5.0

## Workspace and files

- The default data directory is now `{workingDir}/data`, created automatically. Set `LAB_DATA_DIR` or `--lab.data-dir` to choose another directory. **Use `LAB_DATA_DIR=.` to retain the previous launch-directory layout. Existing files are not automatically moved.**
- Show all visible files in the File Browser, with file-type icons. CSV, JSON, XML and text files have independent editable tabs; supported images have preview tabs.
- The launcher provides Java notebooks, an introduction, common CSV/JSON/XML/TXT/YAML/SQL files and image upload. Markdown, Java source, JavaScript, CSS, HTML, Properties and Log cards were removed from the launcher; create those supported text files through **File → New data/text file**. Rename any file with F2, context menus, editor titles or tab-name double-clicks.
- Text editing includes highlighting, line numbers, indentation, bracket pairing, find, undo/redo and JSON/XML formatting. XML validation checks the current draft on the server and reports line/column errors.
- Saves preserve UTF-8 BOM/line endings and detect stale revisions. CSV helpers preserve quoted/multiline fields and string-valued data.

## Images and Markdown

- Preview PNG, JPEG, GIF, BMP, WebP and SVG, with copyable Java/Markdown examples.
- Use the pre-imported `Images.show("opencode.png");` API to display embedded PNG/JPEG/GIF/BMP/WebP/SVG outputs.
- Markdown supports workspace images, web/email links, links to workspace files and section anchors. File links open the corresponding tab; other files download. Heading anchors remain stable across cells, and code examples are left untouched.
- HTML export embeds referenced Markdown images for offline reports and keeps standard links functional.

## Launcher and file browser

- Add distinct icons for notebook, CSV, JSON, XML, images, text, SQL, configuration, source and archive files.
- All visible regular files appear in the File Browser; unrecognized/binary types can be downloaded.

## Vibecode

- Inspect current Java session values and nested/private fields, and discover actual library APIs.
- Include saved CSV file/header metadata in AI context. Prompts favor reusable top-level variables and avoid repeated imports/logic.
- Show live activity, reported models, finish reasons and token usage. Validate generated Java completeness and make one bounded correction attempt before applying.
- Configurable overall timeout and inspection budgets, with final code generation after inspection limits are reached.

## Help

- Searchable offline usage guide covering files, editors, images, Java sessions, data/display helpers, AI, export and all application/environment configuration.
- Keyboard shortcut tables are generated from the current bindings.

Download `java-lab.jar`, run with a full JDK 17+, and restart the application/reload the browser when upgrading. Text and CSV editors use explicit save; notebook cells retain autosave. Markdown image/file paths are relative to the configured data directory. Renaming does not rewrite existing references.
