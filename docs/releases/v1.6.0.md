# Java Lab 1.6.0

## SQL workspace

- Configure JDBC drivers, connection URLs and local credentials directly in SQL files. Execute a selection or the complete file, browse paginated results and export result snapshots as CSV into the File Browser.
- Browse database tables, views and columns with filtering and schema refresh.
- Use SQL AI edits with automatic database schema context and bounded, read-only column/sample inspection tools.
- Load saved SQL files from Java notebooks with the pre-imported `Sql.load(...)` helper, including immutable tables, named records and update counts.
- SQL connection metadata travels with the file; user names and passwords are stored locally under `~/.java-lab/sql-credentials/`.

## AI editing and inspection

- Extend AI edits to notebook Markdown and raw text cells, as well as supported text, JSON, XML, YAML and SQL file editors. Selection-aware edits support undo and discard stale or cancelled responses.
- Add read-only workspace listing and file inspection tools for data conversion and code generation.
- Inspect OpenAPI 3.x / Swagger 2 specifications in JSON or YAML from workspace files or HTTP(S) URLs when generating Java implementations.
- Add bounded database inspection for Java generation, with read-only query validation and automatic JDBC driver resolution.
- Prefer OpenRouter providers by output throughput by default; configure latency, price or normal routing with `AI_OPENROUTER_PROVIDER_SORT`.
- Improve live generation activity with elapsed time, expandable history and model/token diagnostics.

## Kernels and editors

- Display live notebook JVM resource information, including heap usage and CPU activity.
- Improve notebook opening and kernel startup feedback, and manage sessions from the Running panel while keeping document tabs open.
- Refresh text, CSV, SQL and image action bars with compact controls; add CSV record filtering and improve text editing behavior.
- Duplicate any supported file from the File Browser, including with Ctrl / Cmd + D.
- Store notebook-local variable values under `~/.java-lab/notebook-values/`, associated with the absolute notebook path.
- Expand the README, in-app help and shortcut documentation for the new workflows.

Download `java-lab.jar` and run it with a full JDK 17+. Restart the application and reload the browser after upgrading. SQL and text/CSV editors use explicit save; notebook cells retain autosave. Save SQL files and connection settings before using `Sql.load(...)` from a notebook.
